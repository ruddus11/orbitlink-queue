자가 검사: 큐 모듈 단위 동작
==================================================================
넣은 순서                 : N1 N2 S1 E1 N3 E2 S2
꺼낸 순서 (우선순위 모드) : E1 E2 S1 S2 N1 N2 N3
  우선순위 모드: E -> S -> N, 유형 안에서는 먼저 온 순서 PASS
  통계: 유형별 sent/received 일치               PASS
  빈 큐 mq_receive: MQ_ERR_EMPTY                     PASS
  NULL 인자: MQ_ERR_PARAM                            PASS
  없는 유형: MQ_ERR_PARAM                          PASS
  payload 길이 초과: MQ_ERR_PARAM                  PASS
  가득 찬 큐: MQ_ERR_FULL 반환                   PASS
  가득 찬 큐: 실패 콜백 1회 호출            PASS
  Normal이 가득 차도 Emergency 전송 성공      PASS
  peak_length: Normal 16/16 기록                     PASS
  failed: Normal 1건 기록                           PASS
  mq_deinit 후 호출: MQ_ERR_NOT_INIT                PASS
꺼낸 순서 (단일 FIFO 모드): N1 N2 S1 E1 N3 E2 S2
  단일 FIFO 모드: 넣은 순서 그대로          PASS
자가 검사 결과: 실패 0건 -> PASS
